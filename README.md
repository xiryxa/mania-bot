# MANIA Bot

Telegram-бот для бренда охотничьих товаров **MANIA** — автоматизация продаж манков, засидок и аксессуаров.

## Возможности

- Каталог товаров с пагинацией и фото
- Оформление заказа с выбором доставки (Почта, СДЭК, Яндекс)
- Личный кабинет: регистрация, редактирование профиля, история заказов
- Админ-панель: управление заказами, товарами, экспорт в CSV
- Автоматический пересчёт остатков при отмене/возврате заказа
- Уведомления о низком остатке товара

## Стек

- Python 3.11+
- Aiogram 3
- SQLite (aiosqlite)
- FSM для пошаговых сценариев
